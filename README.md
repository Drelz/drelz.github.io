# Drelz
A small selection of mtg-related apps. 

<img width="352" height="312" alt="drelz-main" src="https://github.com/user-attachments/assets/35de91a6-0303-4a9b-b3ec-bbe6f6d5fa72" />

## Grand Sealed Magic
Load a custom deck pool and search the cards, see their stats and create decks.

## Mtg-Deck-Stats
Load a decklist and see various information about it. Number of different cards theirs, their mana cost and curve, color distrubtion etc.

## Mtg-Image-Retriever
Paste a list of cards, and retrieve additional information from scryfall-api about the cards.

## Mtg-Shadowboxing
Load a deck list and have a shadowboxing match. It supports rough magic gameplay.
