## HuskeListe
A personal to-do board. Items live in tag columns (an item can carry several tags), with optional description, deadline, assignee, recurrence (daily/weekly/monthly/quarterly/yearly) and urgent flags. Sort by deadline or A–Z, search across the board, a dedicated Gentagelser tracker to bump recurring tasks, and completed items go to a Done archive. Saved locally per device; installable as an app (PWA) and works offline.

## Grand Sealed Magic
Load a custom deck pool and search the cards, see their stats and create decks.

## Mtg-Deck-Stats
Load a decklist and see various information about it. Number of different cards theirs, their mana cost and curve, color distrubtion etc.

## Mtg-Image-Retriever
Paste a list of cards, and retrieve additional information from scryfall-api about the cards.

## Mtg-Shadowboxing
Load a deck list and have a shadowboxing match. It supports rough magic gameplay.
